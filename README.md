# 思维链浏览器 · CoT Reader

翻看、检索、翻译鲸娘在 DSH 里留下的每一步思考（reasoning）。

## 两种打开方式

| 方式 | 入口 | 需要什么 |
|---|---|---|
| **DSH 内面板** | 侧边栏「🧠 思维链」图标，主区直接显示 | 插件 `@cetacea/dsh-cot-viewer`，装好后**重启一次 DSH** |
| 独立网页 | 双击 `启动思维链浏览器.cmd`，打开 <http://127.0.0.1:7388> | Node ≥ 22.15（脚本默认用 DSH 自带的） |

两者共用同一套解析与翻译逻辑；插件把缓存放在 `~/.dsh/cot-viewer/`，独立网页放在 `data/`。

## 装进 DSH

独立网页不用装，双击 `启动思维链浏览器.cmd` 就能用。想用侧边栏面板：

1. 在 `~/.dsh/profiles/<profile>/package.json` 的 `dependencies` 里加
   `"@cetacea/dsh-cot-viewer": "link:<本仓库路径>/plugin"`；
2. 在同一个 profile 的 `cordis.patch.yml` 里加：

   ```yaml
   - insert:
       - id: dsh-cot-viewer
         name: "@cetacea/dsh-cot-viewer"
   ```

3. 在该 profile 目录装一次依赖（DSH 用的是 `pnpm install`），让 `node_modules/@cetacea` 下出现链接；
4. 重启 DSH，侧边栏就会出现「思维链」。

卸载反过来做，细节见 `plugin/README.md`。

## 怎么用

双击 **`启动思维链浏览器.cmd`**，浏览器会自动打开 <http://127.0.0.1:7388>。

- 左边是全部历史会话，按最后活动时间排序；可以按工作区筛、按「思考条数」排序。
- 中间按「轮 → 步」展开：每一步的思考、调用的工具、当步回复。
- **译文自动出现**：打开会话时，屏幕里能看到的思考会自动翻译成中文；往下滚会接着翻。译文缓存在 `data/translations.jsonl`，翻过的不会重复花钱。
- 原文始终可看：顶部切「原文 / 双语 / 译文」，或者点开灰色原文块。
- **Ctrl K** 搜遍全部历史思维链（支持正则，点 `.*` 开关）；命中结果点一下就跳到那一步并高亮。
- 顶部可以切换翻译模型：DeepSeek 官方（默认）或本地 Ollama；「翻译全部」会把整个会话排进队列（会先确认字数）。
- 「导出」把当前会话（用户消息、原文、译文、工具调用、回复）存成 Markdown。

## 翻译后端

| 后端 | 需要什么 | 说明 |
|---|---|---|
| DeepSeek 官方 | 自动读 `~/.dsh/.credentials.yaml` 里的 `DEEPSEEK_API_KEY` | 质量好、要花额度；没配 key 时在设置里找不到就会报错 |
| 本地 Ollama | `127.0.0.1:11434` 上跑着的模型 | 免费不外传，质量看模型 |

翻译记录按「后端 + 模型 + 原文指纹」缓存，换模型会重新翻。

## 数据从哪来

`~/.dsh/sessions/<工作区>/<会话>/session.v*.jsonl.zstd`，只读，不改动任何原始归档。
新会话要等它落盘后点左上角 `⟳` 刷新才出现（正在进行的会话也能读到已写入的部分，末尾不完整帧会被容错跳过）。

## 文件

```
cot-tool\
  server.mjs              本地服务（零依赖）
  lib\session.mjs         zstd 多帧解压 + 事件折叠
  public\                 前端
  data\settings.json      界面设置
  data\translations.jsonl 翻译缓存
  启动思维链浏览器.cmd    双击启动
```

需要 Node ≥ 22.15（脚本默认用 DSH 自带的那份）。

开发时的自测脚本（解析检查、前端冒烟测试）留在本地 `_probe\`，不随仓库发布。

## 2026-10-25 自检修复

- **长文本分块翻译粘段**：超过 4000 字的思考会分块送上游，块与块之间原来没有分隔，两段译文会粘成一句。现在补一个空行（流式与缓存里都有）。
- **旧归档漏思考**：v0/v1 里只写在 `reasoning-chunks`、`assistant/message` 没带的思考，现在会补回来（09-07 那个会话多出 2 步、约 3.4 万字）。
- **翻译失败不再白花钱**：前端出错时主动关流，不会让上游把整段翻完；流被截断也不会一直卡在「翻译中」。
- **导出带上新译文**：打开会话后翻出来的内容，导出 Markdown 时不再缺。
- **切回译文视图会补翻**：从「原文」切回「译文/双语」、或重新打开自动翻译时，视口附近没翻的块会重新排队。
- **连点会话不再串台**：慢的响应不会覆盖后点开的那个。
- **宿主更稳**：SSE 写失败不会带崩 DSH；坏 JSON 返回 400；翻译缓存改成临时文件 + 改名，进程被杀也不会丢整份缓存。
- **独立网页**：静态目录穿越多一道分隔符判断；`limit=abc` 走默认值 200。

仍然要留意：

- 「译文」视图下原文块是隐藏的，想看原文请切「双语」——README 原来写的「点开灰色原文块」只对双语/原文视图成立。
- 修复前已经翻过的长文本缓存（34 条）内容完整、只是少了空行；需要时点单条「重译」。
- 宿主半边（`plugin\lib\`）改动要重启 DSH 才生效；只改 UI 的话刷新面板即可。
